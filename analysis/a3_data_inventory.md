## 6. Missing measurements (candidate "additional experiment" list)

**None are required for the core P1–P4 comparison.** Everything needed is in
existing logs. Items flagged only as optional strengthening:

1. **Per-k util mean/p95 pre-aggregate** — not stored, but fully reconstructible
   from `util_samples.csv` (no new GPU run). Will derive in Phase 2.
2. **Exact tab:main L2LM & L3VLM worst/mean reconciliation** — values exist in
   `rev9_main_cmp.csv` / `rev22_vlm_sweep.csv`; a small rounding/aggregation
   reconciliation to the paper's printed 0.062 / 0.016 is a Phase-2 desk task,
   not a new experiment.
3. **P3 at intermediate θ where it *would* migrate** — if we also wanted to
   evaluate θ<52% (p95-based), the migrated mixed placements (split1..3) are
   already measured in the split family, so still no new run.

## 7. Conclusion

All four policies (P1–P4) plus the Oracle upper bound are **evaluable entirely
by re-analysis of existing logs**. No new GPU-occupying experiment is needed for
the main A3 deliverable. The only "new" computation is deriving per-k GPU
utilization mean/p95 from the already-logged `util_samples.csv` time series
(Phase 2), which is pure post-processing.
