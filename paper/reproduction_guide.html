Reproduction Guide

Paper: Placement Reversal in Multi-Camera Streaming Detection Under Deployment-Time Contention (paper/main_vision.tex)

What this is: for every table and figure, the data file(s) that hold the numbers and the script/command that reproduces them.

All paths are relative to the repository root. Scripts live in accv_experiments/scripts/, data in accv_experiments/results/. Run with the project venv: .venv/bin/python.

Conventions & environment

Detector
YOLOv11s (FP32 PyTorch on GPU; vendor INT8 .mxq on NPU), 640×640 letterbox
Dataset
Argoverse-HD validation split (24 logs), COCO category mapping per Li et al.
Platform
Intel Core Ultra 9 285K · NVIDIA RTX 5090 · Mobilint MLA100 NPU
Protocol
14 s window, 30-frame warm-up, host post-proc threads = 4, deadline = 1000/30 = 33.333 ms, ≥3 reps (10 at the k=1 boundary)
Core eval
_step_d_common.py (fg_worker, per_stream_sap); never modified by the drivers below
Single-run unification (rev30). The ResNet50 contention axis (Table 4 ResNet row, Fig. 2, Fig. 3, appendix tables) is now produced from one canonical dataset accv_experiments/results/rev30_clean_resnet/rev30_raw.csv (273 rows, per_stream_json retained so Oracle candidates are recomputable). Earlier these came from four separate runs (rev20/21, rev22/24, rev29, rev25).

Table 2 — Single-camera evaluation, negligible skip tab:single-stream

Shows
GPU vs NPU end-to-end latency + per-size sAP (small/medium/large) in isolation, with Wilcoxon p-values.
Primary data
results/rev19_table1_threads4.csv — columns infer_ms, sap_s/m/l, skip_pct, 3 reps × {GPU,NPU}, 24 logs.

Reproduce

p-values
Wilcoxon signed-rank across logs — scripts/phase_rev12_aggregate.py / phase_rev9_aggregate.py (scipy.stats.wilcoxon).
Cell mapping
sAP rows: GPU 0.016/0.184/0.477, NPU 0.008/0.148/0.478 ← csv sap_s/m/l. Latency: NPU 10.0 = NPU infer_ms mean (10.012) ✓.
GPU latency cell 8.5 — flagged. The canonical same-run value is GPU infer_ms mean = 8.258 → 8.3 (rev19_table1_threads4.csv, the same file as NPU 10.0). The printed 8.5 traces to results/compiler_check_summary.md:53 ("reused, not re-measured") and matches a different run (gen_decomp.csv GPU L0 ≈ 8.43) / a p95 statistic — i.e. cross-run. Recommended correction: 8.5 → 8.3 (NPU 10.0 unchanged).
Latency definition (verified): end-to-end per-frame wall-clock = image read + preprocess + inference + host post-processing (dequant/decode/NMS), streaming queueing excluded (skip≈0 so equals delivery latency). Timer: _step_d_common.py:208–211 (rt = time.time()-t0). Same definition for GPU and NPU.
