## 작업 114 — 성립 조건 (**탐색 전에 확정, 이후 조정하지 않음**)

판정 지표는 정본 정의(`docs/metric_definitions.md`, ε=1.0, T=3 s, T_v=3 s, Δ=0.2 s, N_cand=5):

- **위반(violated)**: `v_score > ε`인 샘플이 하나라도 존재 ⇔ $t_0$가 존재.
- **회복(recovered, strict $t_r$)**: 어떤 시점부터 **런 종료까지 계속** `v_score ≤ ε`. 미충족이면 censored.

| 시나리오 | 성립 조건 |
|---|---|
| **Q3 / Q5** (오예측) | **top-1이 위반**하고 **회복 배치가 회복**한다 |
| **Q2 / §4b** (예측 정합) | **위반이 발생**하고 **top-1이 회복**한다 |
| **Q4** (후보 없음) | 예산 내 **어떤 후보도 회복하지 못한다** |
| **Q1.3** (정상상태) | 위반이 발생하고 재구성 기법이 회복한다 |
| **Q6** (2×2) | Q3와 동일 조건·동일 λ |

**재현 기준**: 탐색 단계 1회(거친 격자, 아래 표에 명시), **구간 확정 후 대표값에서만 5회 중 5회 동일 분류**.
→ 구간이 없어 대표값 단계에 도달하지 않았다.

**고정 파라미터**(구성 (a)의 문서화된 값, `docs/q3_experiment_report.md`):
`L_SLO` = 5×Table~I = yolo11s **155**, yolo11m **209**, resnet50 **56**, mobilenet_v2 **32** ms;

## 진단 (작업 117) — 세 가지 중 **"회복 배치가 회복하지 못한다"**

| 후보 진단 | 해당 여부 |
|---|---|
| 워크로드가 가볍다(둘 다 feasible) | λ ≤ 175 구간에서만 해당 — λ를 올리면 해소 |
| **워크로드가 무겁다(회복 배치도 회복 못 함)** | **해당.** λ ≥ 200에서 두 배치 모두 위반·미회복 |
| 구간이 너무 좁다 | 해당 없음 — 좁은 것이 아니라 **비어 있다** |

### 왜 비는가 — 구조적 이유

회복 배치는 top-1에서 **`llama1b`(2 fps) 하나만 CPU로 옮긴 것**이다. 전경 vision 4종이 이미 가속기를
포화시키므로, 2 fps짜리 생성 모델을 빼는 것은 **vision 지연에 사실상 영향이 없다**. 실제로
λ=200에서 회복 배치의 maxV(1.270)가 top-1(1.189)보다 **오히려 높다** — 차이가 측정 잡음 수준이다.

이는 새 발견이 아니라 **07-22 런의 진단과 일치**한다(`docs/q3_experiment_report.md` §3):
> *"(i) **4 vision이 GPU를 포화**시켜 LLM 배치가 결정 요인이 아님"*

즉 07-22의 무효 판정은 "λ=52가 낮아서"만이 아니었다. λ를 올리면 위반은 생기지만
**회복 배치도 같이 위반**하므로 오예측 시나리오가 성립하지 않는다. **λ 조정으로는 해소되지 않는다.**

### 대조 — 3-vision 구성에서는 왜 성립했나
게시 런(구성 (b), vision 3)에서는 생성 모델이 **4개 인스턴스 중 하나**로 가속기 경합의 유의미한 몫을
차지했고, 그것을 CPU로 옮기는 것이 실제로 경합을 해소했다(`cand_5` 회복, 5/5). vision을 4종으로 늘리면
그 지렛대가 사라진다.

## 사람 판단이 필요한 갈림길 (v26 §범위 밖 — 워크로드 재설계)

λ로는 해결되지 않으므로 아래 중 하나가 필요하다. **어느 것도 임의로 택하지 않았다.**

1. **배경 생성 모델을 무겁게** — 예: `qwen2_vl` 추가 또는 llama1b 요청률 상향. 생성 모델이 가속기 경합에서
   유의미한 몫을 갖게 해 "옮기면 해소된다"를 회복.
2. **전경을 3종으로** — 결정 (b)로 되돌아감. 게시 수치와 대조 가능해지나 107 결정을 뒤집는 것.
3. **다른 축의 파라미터** — 버퍼·SLO 규약 변경. **이번 지시문이 승인하지 않은 축**이라 건드리지 않았다
   (탐색은 λ에 한정). SLO를 죄면 위반은 쉬워지나 회복 배치의 열세는 그대로다.

> 미측정: **Q5(cpu-npu)**, **Q4**, **§4b**, **Q1.3**. Q3가 성립하지 않으면 Q6도 성립하지 않으므로
> (동일 워크로드·동일 λ) 먼저 위 결정이 필요하다. NPU는 마진이 3으로 더 넉넉하나, 포화 논리는 동일하게
> 적용될 가능성이 크다 — 결정 후 같은 하네스로 확인할 수 있다.
