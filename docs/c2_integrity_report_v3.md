### 판정 (매트릭스 8-3)
- **Q3·Q5 baseline 3기법(Static/Stop-restart/Adaptive)**: 미회복(lastV Q3 ~2.8, Q5 ~33 ≫ ε=1), 0/5, censdur ≈
  dur → **표기 결함(2행).** 보고된 persist 105–106(Q3)·113–114(Q5)은 **회복 시간이 아니라 런 길이.**
  게다가 baseline은 107s 런, BoundGuard는 83s(Q3)·98s(Q5) 런 — **서로 다른 윈도우를 나란히 비교.**
- **Q1.3 Static(양 플랫폼)**: 미회복(lastV 9.0), censdur 58.4 = dur → **표기 결함.** "59.4s persistence"는 런 길이.
  단 Q1.3의 **회복 3기법(Stop-restart/Adaptive/BoundGuard)은 진짜 회복**(5/5, persist 11–13s) — 이 대비는 유효.
- **BoundGuard 회복값(Q3 25.4·Q5 21.0·Q1.3 11–12)은 진짜 persist**(5/5, lastV 0).

**결론**: baseline persist는 전 실험에서 censored. "105 vs 20"(Q3)·"59.4 vs 9–12"(Q1.3 Static) 형태의 **배수 대비는
성립하지 않는다**(런길이 ÷ 회복시간). 그러나 **"baseline은 창 종료까지 회복 못 함 vs BoundGuard는 회복"**은
참이며 더 강한 진술. **게이트 결과: §IV 표 구조 변경 필요 → 작업 9·10을 반영 권고로 승격.**

## 작업 9 — v2 내부 불일치

### 9-1. 정본 persist 단일화 — **23.6±2.3s**
- v2 §6-4(23.6±2.3, 풀링 30)와 §7 표(21.4±3.4, 매트릭스 5회)는 **같은 지표의 다른 표본**이었다. 21.4는
  매트릭스 **단일 배치**(15s 정상 이상치 포함)이라 낮고 SD 큼. **정본 = 풀링 30회 23.6±2.3s(최대 28, 최소 15).**
  §7 표는 이 값으로 통일(아래 §7 정정).
- **main.tex 20.0의 정체**: 같은 원본(b2rep_q3)을 metrics_lib strict(wall-clock)로 재측정하면 25.4다. 20.0은
  hot-swap 전환 중 샘플 간격(전환이 샘플링을 잠시 멈춤)을 누락해 **과소보고**한 값. 정본은 wall-clock 기준 ~24s.

### 9-2. §4b cens 107 규명 — **정의상 가능 (t0 < t_inject)**
- §4b는 **stable 단계(all-CPU @ LOW=8fps)가 이미 위반**(V~6). 따라서 `t0`(첫 V>ε)가 **t_inject보다 7s 앞선다**
  (t0는 stable 구간). `cens = 윈도우종료 − t0 = 100 − (−7) = 107`. 다른 시나리오는 t0가 burst 이후라 <100.
- **SD 0.0은 정상**: t0가 stable 온셋(고정 스케줄 오프셋)에 pinned → 결정적. 단일 런 복제 아님(5런 모두 동일 구조).
- **정정**: §7 §4b cens는 t_inject 기준(≤100)으로 통일하거나 "t0가 창 앵커에 선행(§4b stable 위반)"을 각주로 명시.
  §4b의 recovering 변형 persist(~19s)도 t0가 stable에 있어 stable+burst를 포함 — 전 변형 동일 t0라 비교는 공정.

## 작업 10 — 배치 분산 재검정 (전 배치)

고정 윈도우 사후 **전 Q3 BoundGuard 런**(매트릭스 5 + work6 5배치×5 = **6그룹, n=30**) ANOVA:

| batch | reps | mean |
|---|---|---|
| matrix | 24,15,21,24,23 | 21.4 |
| w6b1 | 27,23,22,27,25 | 24.8 |
| w6b2 | 28,23,23,22,24 | 24.0 |
| w6b3 | 24,25,25,24,25 | 24.6 |
| w6b4 | 24,23,22,24,24 | 23.4 |
| w6b5 | 25,23,25,21,24 | 23.6 |

- **F = MS_between/MS_within = 1.55** (df 5,24), 5% 임계 ~2.62 → **유의한 배치 효과 없음.** σ²_between=0.53(SD_b 0.73).
- work6만(F 0.64)보다 상승 — 매트릭스 배치가 15s 이상치로 낮아 between 분산을 키움. 지시문 예측 F≈2.6보다는 낮음.
- **15s = matrix rep2**: cand_1→2→3→4→5 정상 순회 후 cand_5에서 회복(lastV 0.00), **walk가 빠르게 진행된 정상
  빠른 회복.** 이상치 아님, **폐기하지 않음**(persist 분포 하단 min 15).
- 매트릭스 vs work6 실행조건: 둘 다 고정 윈도우·순차·warmup 동일. 매트릭스는 q3→s4b→q4 순의 첫 블록,
  work6는 이후 전용 실행. **모두 동일 세션.** 별도 세션·기기 간 검정은 미실시(범위 밖).

### 판정 (매트릭스 10-3)
- F(1.55) < 임계(2.62) → **"배치 효과 없음" 유지 가능하되**, work6만의 F 0.64보다 상승했으므로 주장을 안전하게
  **"동일 세션 내 6배치 간 유의한 효과 미관측(F=1.55)"**으로 좁힌다. 정본 SD는 **전 배치 풀링 2.3s** 사용.
- 역사적 6.4s 산포가 런길이+정의혼동 아티팩트라는 v2 설명은 **유지**(고정 윈도우에서 배치평균 21.4–24.8로 수렴).
