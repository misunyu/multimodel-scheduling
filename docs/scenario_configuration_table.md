## 핵심 불일치 세 건 (본문 정정 대상)

1. **전경 개수**: §IV-A는 4종(YOLO11s/11m/ResNet50/MobileNet-v2)이라 단언하나, **미스프리딕션 계열
   (Q3/Q5/Q6)과 Q4 2-gen은 3종**(yolo11m 없음)이다. 4종 변형은 시도됐고 **무효 판정**됐다
   (`hotswap_buffer_bias_fix.md §6c`). heavy-4 Q4만 4종이며 그마저 **구성이 다르다**
   (yolo11x/l/m + resnet50 — MobileNet-v2 없음, YOLO11s 없음).
2. **$L_{SLO}$ 규약**: §IV-A는 $5\cdot\text{latency}_i$를 무조건문으로 적으나 **최소 세 규약이 공존**한다
   (균일 15 / 5×Table I / per-frame 8.13 ms).
3. **λ·버퍼**: 실험마다 다르다(40 / 45 / 80 / 90 / 0.9μ\*; B = 2 / 12 / 300 / 2000 / β_B 스윕).

## §2.3 — 균일 15 ms가 만드는 비대칭 (확인 결과)

규칙값($5\times$Table I) 대비 균일 15 ms는:

| 모델 | 5×latency | 균일 15 | 상대 |
|---|---|---|---|
| yolo11s | 31.0 ms | 15 ms | **2.1× 더 엄격** |
| resnet50 | 11.2 ms | 15 ms | 1.3× 더 느슨 |
| mobilenet_v2 | 6.4 ms | 15 ms | **2.3× 더 느슨** |

→ 해당 실험의 $V(t)$는 **사실상 yolo11s가 지배**한다. 본문이 세 모델의 평균으로 읽히므로 명시가 필요하다.

### 회복 방향이 세 모델에서 동일한지 — 로그 확인
회복 배치(`cggg`: llama1b→CPU, 비전 3종 GPU 유지)는 **세 비전 모델 전부의 조건을 개선한다**:
경쟁하던 LLM이 GPU에서 빠지고 세 모델 모두 GPU에 남으므로, 어느 모델도 디바이스가 나빠지지 않는다
(비전 배치 불변, 경쟁자만 제거). 실제 로그에서도 회복 후 세 뷰 모두 대기시간·드롭이 감소한다
(예: cand_5에서 mobilenet_v2 drops 108→59, resnet50 wait 3.41→5.62는 소폭 증가하나 backlog는 해소).
**어느 모델에서도 회복과 반대 방향으로 움직이지 않는다** → §7 단서("확인 결과 다르면 보고하고 멈춘다")에
해당하지 않으며, **결론은 유지**된다.

> 단, 이 확인은 **집계 요약 수준**이다(원시 시계열 부재). 모델별 $V_i(t)$ 분해는 로그에 없으므로
> "yolo11s 지배"는 SLO 값에서 오는 **구조적 귀결**로 서술해야지 측정으로 서술하면 안 된다.
