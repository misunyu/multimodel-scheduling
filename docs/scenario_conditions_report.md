→ 위반이 발생하고 top-1이 그것을 해소한다. **대조군 성립.**

### Q4 — **만족** (λ=90, buf=300, 전 후보 측정)

### Q5 — λ 조정 후 **만족** (λ=45, buf=12)

`q5_experiment_report.md`가 *"Q5 전체 4기법 실험은 NPU 전용 λ 튜닝이 별도 필요"*로 남겼고 게이트 D도
**Q5 최종 λ를 미상**으로 기록했다. 규정대로 **Q5만** 조정했다(다른 시나리오 불변).

| λ | top-1 maxV | 회복 배치(cand_2) 위반/회복/maxV | 조건 |
|---|---|---|---|
| 25 | 13.03 | ✗ / — / 0.000 | 만족 |
| 40 | 26.35 | ✗ / — / 0.005 | 만족 |
| **45** | 27.75 / 26.97 | ✗ / — / 0.009 · 0.011 | **만족 (2/2 재현)** |
| 55 | 28.69 | ✗ / — / 0.451 | 만족 |
| 65 | 29.49 | ✓ / ✓ / 2.520 (lastV 0.720) | 만족 |
| 80 | 30.31 | ✓ / **✗** / 3.623 | **불만족** |

**성립 구간(확인 범위): λ ≤ 65**, 80에서 깨진다. 사전 고정 규칙(v26 작업 116-1 **구간 중앙**)을
확인 구간 [25, 65]에 적용 → **λ = 45**. 대표값에서 **2/2 재현** 확인.

> λ 통일(규칙 3)은 **불가**: Q3(CPU–GPU)는 80에서 성립하나 Q5(CPU–NPU)는 80에서 깨진다.
> 플랫폼의 $\mu^\ast$가 다르기 때문이다(GPU ≈137 fps vs NPU ≈103 fps, `c3_stress_report.md`).
> 사유를 적고 시나리오별로 둔다.
