## 결론

**측정은 안정됐지만, 사전 규칙을 모두 만족하는 β는 없다.** 지시문대로 중단하고 보고한다. §5.4(반복 편차, LM-free N=6)는 선택된 β가 없어 실행하지 않았다.

- **반복 편차는 해결됐다.** 같은 배치 3회의 F 상대 범위가 중앙값 0.57%, 최대 4.0%다(Phase 1: 2회 차이 중앙값 9.2%, 최대 29.3%). 36개 배치 전부 5% 안이다.
- **Conservation은 전부 정확히 0이다.** 171 runs, instance 738개에서 timestamp 기준 오차 0, 요청 추적 불일치 0, invalid run 0.
- **β별 미통과 사유** — 폭이 작은 것과 구조적인 것이 섞여 있다.

## 4. Drop metric (§5.5, 참고)

Workload 12개, pilot 후보 3개씩, 3회 평균. "best"는 pilot 후보 안의 best-measured.

## 6. 원고 영향 갱신

- 모델 8종. TinyLLaMA 제외 사유: 보유 파일이 int4 양자화본(909.5 MB)이라 서술과 다르고, 10 s 구간 완료 건수가 부족하며, GPU 배치에서도 CPU를 포화시킨다.
- Family 22개, 평가 workload(N≥3) 12개(기존 18개). 최대 N은 7.
- 실행 조건: ONNX Runtime 1.23.2, session당 intra-op thread 4, spinning off, nice 없음. 요청 생성기는 별도 process.
- GPT-2의 GPU 실행은 kernel 시간의 27%가 CPU에서 돈다는 점.
- 요청 rate 규칙 `β × GPU isolated throughput × 배수`와 β 값(미정). CPU isolated capacity는 thread 4 기준 값으로 교체.
- Δ = warm-up 5 s + 10 s. 전처리는 표준 ImageNet 변환(추인됨).
- CPU–NPU는 보류. 기존 NPU 결과는 새 정의로 재사용 불가.
- Phase 1 보고서 7절의 나머지 항목(중간 rate 제외에 따른 삭제 등)은 그대로다.
